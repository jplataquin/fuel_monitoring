3\. Real-Time Performance & Audio Safety Constraints

• ZERO Heap Allocations: Pre-allocate all static ring buffers, FFT partitions, and state variables as fixed arrays (\[f32; N\]) inside structs. Strictly forbid Vec::new(), Box::new(), or malloc during process\_buffer().  
• Parameter Smoothing: Apply 1st-order exponential low-pass smoothing (10 ms time constant) to all UI control parameters inside process\_buffer() to eliminate zippering noise/clicks during fast slider movements.  
• Scoped Antialiasing: Enclose ONLY non-linear clipping stages (Preamp Cohen-Helie wave-shaper and Power Amp EL34) in a 2x/4x oversampling block using half-band FIR filters. Do not oversample linear stages (Tone Stack, FIR Cab IR, Reverb) to conserve CPU cycles.  
• Stereo Buffer Output Mapping: Process DSP internally in mono, then explicitly copy the final mono audio frame to both Left and Right output buffers (output\[0\] and output\[1\]) in the Web Audio Worklet handler.  
• Static Delay Line Bounds: Pre-allocate fixed-size array buffers for Reverb delay lines at instantiation time based on maximum supported sample rate (96 kHz).  
• Equal-Power Crossfading: Apply equal-power crossfades during dynamic IR swaps or FX loop routing changes to avoid audio pops.
